# SEYOUNG.zip — 황세영의 작은 우주

건양대학교 방사선학과 2학년 황세영의 개인 홈페이지입니다. 트렌디한 소개 페이지, 엠씨더맥스 공식 유튜브 영상 재생목록, 브라우저 안에서 플레이하는 테트리스 스타일 게임을 제공합니다.

## 실행 방법

`index.html` 파일을 더블클릭해 웹 브라우저로 열면 됩니다. 설치나 서버 실행이 필요하지 않습니다. 음악 재생은 인터넷 연결이 필요합니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 **Public** repository를 만들고, 예를 들어 `seyoung-homepage`라고 이름 붙입니다.
2. 이 폴더의 **`index.html`, `style.css`, `script.js`** 파일을 저장소의 **최상위(루트)** 에 업로드하고 커밋합니다. (`README.md`도 함께 올려도 됩니다.)
3. 저장소 → **Settings** → **Pages** → **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`를 선택하고 **Save**를 누릅니다.
5. 배포가 완료되면 `https://사용자이름.github.io/seyoung-homepage/` 주소로 접속할 수 있습니다.

## 게임 조작

- `←`, `→`: 좌우 이동
- `↑`: 블록 회전
- `↓`: 한 칸 내려가기
- `Space`: 바로 떨어뜨리기
- `P`: 일시정지 / 재개
- `R`: 처음부터 시작
- 휴대전화: 게임 아래의 터치 버튼 사용

10줄을 지울 때마다 레벨이 올라갑니다. 한 번에 여러 줄을 지우면 더 많은 점수를 얻습니다.

## 음악 안내

공식 유튜브 영상 3개를 선택해 재생할 수 있습니다. 원본 음원 파일을 다운로드하거나 사이트에 재배포하지 않습니다. 영상 소유자의 임베드 허용 정책 및 시청자 네트워크 환경에 따라 사이트 내 재생이 불가능할 수 있으며, 이 경우 각 곡의 **유튜브에서 열기** 링크를 이용하세요.

- 어디에도 — MUSIC&NEW 뮤직앤뉴 공식 MV
- 넘쳐흘러 — 1theK 공식 MV
- 행복하지 말아요 — OGAM 제공 YouTube 음원 영상

## 개발 기술

Vanilla HTML / CSS / JavaScript. 외부 프레임워크 없이 GitHub Pages에서 작동하도록 구성했습니다.
